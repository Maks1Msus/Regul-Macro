# Anime Adventures Macro

Первая версия на AutoHotkey v2 выполняет один цикл в открытом матче. Она выбирает слот, ставит юнита в сохранённую точку, ждёт доступного улучшения и подтверждает его по интерфейсу. Каждый образец и точка сохраняются в профиле карты.

## Запуск

1. Распакуй архив в папку с правом записи. Запусти `Main.ahk` через **AutoHotkey v2**.
2. Открой Anime Adventures в оконном режиме, вручную зайди на выбранную карту и приведи камеру к ракурсу, который можешь воспроизвести. Сделай окно Roblox активным и нажми **F6**.
3. Калибруй первый профиль в пробном матче. Для захвата образца наведи указатель на один угол элемента, нажми сочетание, затем повтори его на противоположном углу. Подойдёт участок от 8×8 до 240×120 пикселей. Выбирай устойчивый фрагмент без движущегося фона и эффектов.

| Клавиши | Что сохранить или сделать |
| --- | --- |
| **F6** | Привязать активное окно Roblox. Первый запуск запоминает размеры игровой области. |
| **Ctrl+Alt+M** | Признак активного матча. Подходит неподвижная часть HUD, видимая в том числе при открытом меню юнита. |
| **Ctrl+Alt+P** | Точка установки под указателем. Сохрани её до первого размещения. |
| **Ctrl+Alt+I** | Постоянный фрагмент меню выбранного юнита. Он должен совпадать до и после первого улучшения. |
| **Ctrl+Alt+U** | Метка в центре **активной** кнопки улучшения. Макрос кликнет в центр захваченного фрагмента. Выбирай участок, который заметно отличается от неактивной кнопки. |
| **Ctrl+Alt+L** | Уникальный признак нового уровня после первого улучшения, например надпись уровня. |
| **Ctrl+Alt+G** | Необязательный признак режима установки, например подсветка слота. Если образец задан, макрос ждёт его после выбора слота. |
| **Ctrl+Alt+A** | Необязательный признак успешной установки, например изменившийся счётчик юнитов. Нужен для автоматического открытия меню, если игра сама его не открывает. |
| **F10** | Проверить, какие образцы найдены на текущем экране. |
| **F8** | Запустить установку и одно улучшение. |
| **F9** | Остановить сценарий или сбросить ввод углов при калибровке. |

4. В пробном матче установи юнита и открой его меню. Сними образцы меню и доступной кнопки, затем вручную улучши юнита и сними образец нового уровня. Проверь их в нужных состояниях через **F10**. Образец уровня должен находиться только после улучшения, а активная кнопка должна отличаться от неактивной.
5. Для прогона войди в новый матч на той же карте, восстанови ракурс и закрой меню юнитов. На первом тесте дождись денег на установку. Нажми **F8**. Макрос использует слот **1** по умолчанию. Если меню само не открылось и образец **Ctrl+Alt+A** ещё не настроен, у тебя есть 16 секунд, чтобы открыть меню установленного юнита вручную.

Горячие клавиши работают в активном окне Roblox. При потере фокуса, смене размера или исчезновении признака матча макрос останавливается. Если клик улучшения не получил визуального подтверждения, макрос завершает попытку после тайм-аута.

## Профили и диагностика

- Образцы и настройки находятся в `profiles/story_first_map/`. В `profile.ini` можно поменять `UnitKey` на цифру от 1 до 9. Сочетания захвата перезаписывают образцы текущего профиля.
- Чтобы завести независимый профиль, открой PowerShell в папке макроса и выполни `& 'C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe' .\Main.ahk story_map_2`.
- Результат и причины остановки записываются в `runtime/<профиль>.log`. Если макрос принял неактивную кнопку за активную, пересними образец на выраженном отличии и проверь оба состояния через F10.
- `src/Screen.ahk` отвечает за окно, клики и образцы. `src/Profile.ahk` хранит калибровку. `src/FirstRun.ahk` выполняет короткий сценарий и подтверждает шаги.

Эта версия начинает работу внутри матча. Вход из лобби, очередь и переподключение относятся к следующим этапам. Профиль первой карты нужно заполнить из живого интерфейса, поэтому архив поставляется без координат и игровых образцов.
